# claude-workflow-kit

Reusable Claude Code development-workflow toolkit, extracted from an existing project setup so it can be installed into any repository.

Planned scope:

- `workflow-core` — workflow definitions, state machine, run model, event schema, gates
- `claude-adapter` — reusable skills, agents, hooks, CLAUDE.md managed block
- `monitor-server` — event ingestion, run state, realtime updates
- `monitor-ui` — live workflow diagram
- `installer` — init / update / doctor / uninstall

Status: architecture not yet approved. No implementation code committed.
